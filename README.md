CareerLens AI: Advanced Resume and Skill Analytics Platform 
• Built a system that accepts a user’s resume as input. 
• Extract skills, certifications, experience and communication keywords using NLP, then analyze the extracted information to identify outdated skills, personality traits, suitable job roles and career strengths and weaknesses. 
• Provides recommended job roles, skill-obsolescence alerts, personality-skill alignment results, a multifactor career score with explanations, and personalized career improvement suggestions.
